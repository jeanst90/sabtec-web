# Guia Rápido — Sabtec

## Novo orçamento
1. Clientes → selecione/crie cliente.
2. Novo orçamento → selecione aparelho → diagnóstico → itens → valores → Criar.
3. Ver PDF → Enviar e-mail/WhatsApp.

## Nova garantia
1. Orçamentos → abra aprovado → Gerar garantia.
2. Preencha serviços/peças → assinatura do cliente → Criar.
3. Ver PDF → Enviar.

## Atalhos
- Dashboard: pendências e garantias vencendo.
- Analytics: faturamento e conversão.
- Relatórios: exportar CSV.
