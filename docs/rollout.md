# Plano de Rollout

## Fases
1. **Piloto (semana 1-2):** 2 técnicos + 1 atendente. Feedback diário.
2. **Expansão (semana 3-4):** todos os técnicos. Suporte on-call.
3. **Estabilização (semana 5+):** ajustes, automações, monitoramento.

## Critérios de sucesso
- 100% dos orçamentos via sistema.
- Tempo médio de emissão ≤ 2 min.
- NPS ≥ 8.

## Rollback
- Manter processo manual como fallback por 30 dias.
- Backup diário do banco.
